# 📊 Superstore Sales Performance Dashboard (2014–2017)

## 📌 Project Overview
This interactive Excel dashboard analyzes Superstore sales data from 2014 to 2017. The goal of this project is to track overall sales, profit, quantity, and customer trends across different regions, segments, and product categories.

## 🛠️ Tools & Skills Used
**Microsoft Excel**
**Data Cleaning & Transformation:** Added calculated columns (Month, Year, Shipping Days) and formatted raw data into structured Excel Tables.
**Pivot Tables & Charts:** Summarized key metrics for visualization.
**Interactive Slicers:** Added filters for *Year, **Region, and **Segment* for dynamic analysis.

## 📈 Key Metrics (KPIs)
**Total Sales:** $2,297,201
**Total Quantity:** 37,873
**Total Profit:** $286,397

## 💡 Key Insights
**Top Region:** West region generated the highest share of sales, followed by East.
**Shipping Preference:** Standard Class is the most preferred shipping mode among customers.
**Category Performance:** Technology and Office Supplies drive strong profits compared to Furniture.
